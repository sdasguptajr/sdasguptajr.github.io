# sdasguptajr.github.io

Personal GitHub Pages site for Sourav Dasgupta. Deployed via the special repository **sdasguptajr.github.io**.

## Edit these quickly
- `index.html`: Update LinkedIn link, project links, and copy.
- `styles.css`: Colors, layout, and spacing.
- `script.js`: Small UX niceties (smooth scroll, etc.).

## Local preview
Open `index.html` directly in your browser.

## Deploy
1. Create a public repo named **sdasguptajr.github.io** in your GitHub account.
2. Upload these files to the root (or push via Git).
3. Visit **Settings → Pages** to confirm the site builds.
4. Open https://sdasguptajr.github.io
